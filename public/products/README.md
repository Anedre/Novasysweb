# Imágenes de producto (HP / HPE)

Colocá acá las imágenes oficiales de producto. Aparecen automáticamente en las
cards de `/infraestructura` (si el archivo no existe, se muestra un placeholder elegante).

## Archivos esperados (nombres exactos)

| Archivo | Card | Sugerencia de imagen |
|---|---|---|
| `computo.png` | Equipos de cómputo | Laptop HP EliteBook / ProBook |
| `servidores.png` | Servidores HPE | Servidor HPE ProLiant DL (rack) |
| `almacenamiento.png` | Almacenamiento HPE | Array HPE Alletra / Nimble |

## Especificaciones

- **Formato:** PNG (ideal con fondo transparente o blanco) o JPG.
  Si usás JPG, renombrá el archivo a `.png` **o** avisame para cambiar la extensión en el código.
- **Proporción:** aprox. 16:10 horizontal (las cards recortan a ese ratio con `object-fit: cover`).
- **Tamaño:** ~1200×750 px, < 300 KB (optimizá antes de subir).
- **Origen:** como HP Gold Partner, descargalas del portal de assets de HP/HPE
  (imágenes oficiales de producto con derechos de uso para partners).

Una vez que las dropees acá, recargá la página y reemplazan al placeholder sin tocar código.
